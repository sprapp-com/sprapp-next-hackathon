# Sprapp — Hackathon Project

A small experiment in running compact language models on commodity CPUs.

## About

Sprapp explores tiny, efficient AI: small custom language models served by a
lightweight CPU inference engine, with a simple web front end for trying them out.

- Compact models that run without a GPU
- An OpenAI-compatible inference endpoint
- A minimal web UI for chat and demos

## Status

Prototype built for a hackathon. Not production software. No warranty.
